## Computational environments

The Pix2Pix and CycleGAN workflows use separate Conda environments.

- Pix2Pix: `conda activate pix2pix`
- CycleGAN: `conda activate cyclegan`

The quantitative analyses were run without dedicated Conda environments.

For access through the lab desktop environment, run `mlc open` and select
`cees_pix2pix`.
